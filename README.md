# 💎 Diamond Price Analysis Dashboard | Power BI

## 📌 Project Overview

This is a beginner-level Data Analytics project created using **Microsoft Power BI**. The project explores diamond pricing patterns and characteristics using a dataset of **53,940 diamond records**.

The dashboard presents insights through interactive visualizations, helping users understand how diamond price, carat weight, cut quality, color, and depth relate to one another.

## 🎯 Project Objectives

- Analyze diamond prices across different cut categories.
- Explore average carat weight across different color grades.
- Understand the distribution of diamonds by color.
- Examine the relationship between carat weight and price.
- Compare average diamond depth across cut categories.

## 📊 Key Questions Answered

This dashboard explores the following analytical questions:

1. Which diamond cut category has the highest average price?
2. Which cut category has the lowest average price?
3. How does average carat weight vary across different diamond colors?
4. Which diamond color category has the highest number of records?
5. What is the relationship between diamond carat weight and price?
6. How does average diamond depth vary across different cut categories?
7. How does the distribution of diamonds change when different color categories are selected?

## 📈 Dashboard Visualizations

- **Average Price by Cut:** Compares the average price across five cut categories.
- **Average Carat by Color:** Shows how average carat weight varies across color grades.
- **Carat vs. Price:** Uses a scatter plot to explore the relationship between carat weight and price.
- **Number of Diamonds by Color:** Displays the distribution of diamond records across seven color categories.
- **Average Depth by Cut:** Compares average depth across different cut categories.

## 🔍 Key Findings

- Premium cut diamonds have the highest average price (approximately $4,584).
- Ideal cut diamonds have the lowest average price (approximately $3,458).
- Color J has the highest average carat weight (1.16).
- Color G has the highest number of diamonds, with 11,292 records (20.93%).
- The scatter plot shows a strong positive relationship between carat weight and price.

## ✨ Interactive Dashboard Features

- Interactive visual filtering and cross-filtering.
- Dynamic updates across multiple charts.
- Hover tooltips for detailed information.
- Multiple visualizations in a single dashboard.
